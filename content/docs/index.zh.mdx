## 什么是 ClothCraft？

ClothCraft 是一个 **AI 换衣产品**，可以把模特图和衣服图合成为真实自然的服装试穿视觉。产品包含用户认证、Creem 订阅、每日使用限制、Seedream 图片生成、R2 媒体存储和中英文营销页面。

### 核心特性

- **用户认证** — 邮箱密码 + Google OAuth（Better Auth）
- **换衣权限规则** — 匿名用户需登录，免费用户每日可生成带水印试穿图，付费用户获得更高日额度
- **AI 集成** — 基于火山引擎 / Seedream 的图生图换衣能力
- **管理后台** — 用户管理、积分调整、订阅控制
- **国际化** — 完整的中英文支持（next-intl）
- **邮件系统** — 交易邮件（Resend）：验证、密码重置、购买确认
- **营销页面** — 首页、定价、博客（MDX）、法律页面

### 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | Next.js 16 (App Router) + React 19 |
| 样式 | Tailwind CSS + Framer Motion |
| 数据库 | PostgreSQL + Drizzle ORM |
| 认证 | Better Auth |
| 支付 | Creem |
| AI | 火山引擎（豆包 API） |
| 邮件 | Resend |
| 国际化 | next-intl |
