## What is ClothCraft?

ClothCraft is an **AI outfit try-on product** for turning model and garment photos into realistic fashion visuals. It includes authentication, Creem subscriptions, daily usage limits, Seedream image generation, R2 media storage, and internationalized marketing pages.

### Key Features

- **Authentication** — Email/password + Google OAuth via Better Auth
- **Try-On Access Rules** — Anonymous users must sign in, free users get daily watermarked trials, and paid users get higher daily limits
- **AI Integration** — Image-to-image outfit generation powered by Volcano Engine / Seedream
- **Admin Dashboard** — User management, credit adjustment, subscription control
- **Internationalization** — Full English and Chinese support via next-intl
- **Email System** — Transactional emails via Resend (verification, password reset, purchase confirmation)
- **Marketing Pages** — Landing page, pricing, blog (MDX), legal pages
